# Ramanuja — Personal Portfolio

A responsive, single-page portfolio for Ramanuja, an aspiring software developer learning Java, Python, and C.

## Files

- `index.html` — portfolio content and structure
- `style.css` — responsive visual design
- `script.js` — mobile navigation behavior
- `README.md` — this guide

## Personalize the portfolio

1. Open `index.html`.
2. Replace `your.email@example.com`, social links, and every `[placeholder]`.
3. Add your real projects, GitHub URLs, education, and contact details.
4. Do not claim skills, experience, or results that you cannot explain.
5. Open `index.html` in a browser to preview the site.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages** under **Code and automation**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and the `/ (root)` folder, then save.
5. GitHub will provide your published portfolio URL after deployment.
